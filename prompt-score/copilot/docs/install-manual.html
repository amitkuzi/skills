Prompt Score in Microsoft Copilot

Visual install guide · version 0.3.0 · 2026-10-27

Every prompt gets a 1–100 prompt-engineering score, its biggest gap, and a menu: breakdown, tips, rewrite, history.

⚠ שני מסלולים: A — חשבון עבודה/בית־ספר עם Microsoft 365 Copilot (סוכן מותקן, קבוע). B — אפליקציית Copilot הפרטית (בלי סוכנים: מדביקים הנחיה בתחילת כל צ'אט). אם הסוכן לא יכול להריץ Python, השורה תסומן (estimated) והציון מקורב.

⚠ Two tracks: A — work/school account with Microsoft 365 Copilot (installed agent, permanent). B — personal Copilot app (no agents: paste an instruction at the start of each chat). If Copilot cannot run Python, the line is marked (estimated) and the score is approximate.

בונים את החבילה

Build the package

Illustration / המחשה

פתחו PowerShell בתיקייה שמכילה את prompt-score והריצו:

Open PowerShell in the folder that contains prompt-score and run:

powershell -ExecutionPolicy Bypass -File prompt-score\copilot\install.ps1

✔ תוצאה: מופיעה השורה Prompt Score v0.3.0 (2026-10-27) ותיקיית dist נפתחת עם P1 ו־P2.

✔ Result: the line Prompt Score v0.3.0 (2026-10-27) appears and the dist folder opens with P1 and P2.

⚠ הודעה שמתחילה ב־failed: מציינת מה נכשל, למה, ומה הצעד הבא — פעלו לפיה והריצו שוב. הדגל -ExecutionPolicy Bypass חל רק על הרצה זו.

⚠ A message containing failed: says what failed, why, and the next step — follow it and run again. -ExecutionPolicy Bypass applies to this one run only.

מעלים את P1 ל־Teams

Upload P1 in Teams

Illustration / המחשה — menu labels can differ slightly between Teams versions

ב־Teams: Apps ‹ Manage your apps ‹ Upload an app ‹ Upload a custom app ‹ בחרו את P1 ‹ Add.

In Teams: Apps › Manage your apps › Upload an app › Upload a custom app › choose P1 › Add.

⚠ אין אפשרות Upload a custom app? המנהל צריך לאפשר העלאת אפליקציות מותאמות, או להעלות את P1 במרכז הניהול: Microsoft 365 admin center › Integrated apps.

⚠ No “Upload a custom app” option? Your admin must allow custom app upload, or upload P1 in Microsoft 365 admin center › Integrated apps.

3

פותחים את הסוכן ב־Copilot

Open the agent in Copilot

Illustration / המחשה

באפליקציית Microsoft 365 Copilot (או ב־Copilot Chat): בחלונית Agents בחרו Prompt Score. ייתכן שיחלפו כמה דקות עד שיופיע.

In the Microsoft 365 Copilot app (or Copilot Chat): in the Agents pane, pick Prompt Score. It may take a few minutes to appear.

4

בדיקה סופית

Final check

Illustration / המחשה — expected text comes from the scorer itself

שלחו fix it. התשובה צריכה להתחיל ב־Prompt score: 10/100 (weak). שלחו about — צפוי v0.3.0 מתאריך 2026-10-27.

Send fix it. The reply should start with Prompt score: 10/100 (weak). Send about — expect v0.3.0, released 2026-10-27.

⚠ מופיע (estimated)? Code Interpreter לא זמין ברישיון/בסביבה שלכם; הציון מקורב. גרסה ישנה מופיעה? העלו שוב את P1 החדש — כל בנייה מעלה גרסה רק אם עודכן plugin.json.

⚠ Seeing (estimated)? Code Interpreter is not available in your license/tenant; the score is approximate. Old version shown? Upload the new P1 again — a rebuild only changes the version when plugin.json was bumped.

מעתיקים את ההנחיה ופותחים את Copilot

Copy the instruction and open Copilot

Illustration / המחשה

powershell -ExecutionPolicy Bypass -File prompt-score\copilot\install.ps1 -Consumer

הסקריפט בונה, מעתיק את P2 ללוח ופותח את copilot.microsoft.com. אפשר גם לפתוח את אפליקציית Copilot ידנית.

The script builds, copies P2 to the clipboard and opens copilot.microsoft.com. You can open the Copilot app yourself instead.

6

מדביקים בתחילת צ'אט חדש

Paste at the start of a new chat

Illustration / המחשה

הדביקו (Ctrl+V) ושלחו (Enter). מעכשיו, באותו צ'אט, כל פרומפט מקבל ציון. בדקו עם fix it כמו בשלב 4.

Paste (Ctrl+V) and send (Enter). From now on, in that chat, every prompt is scored. Check with fix it as in step 4.

⚠ ההנחיה תקפה רק לצ'אט הנוכחי — בכל צ'אט חדש מדביקים שוב. Copilot הפרטי לא תמיד מריץ Python, ולכן הציון עשוי להיות מסומן (estimated).

⚠ The instruction lasts for the current chat only — paste it again in every new chat. Personal Copilot does not always run Python, so the score may be marked (estimated).
