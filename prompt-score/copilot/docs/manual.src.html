Prompt Score in Microsoft Copilot

Visual install guide · version {{VERSION}} · {{DATE}}

Every prompt gets a 1–100 prompt-engineering score, its biggest gap, and a menu: breakdown, tips, rewrite, history.

⚠ שני מסלולים: A — חשבון עבודה/בית־ספר עם Microsoft 365 Copilot (סוכן שבונים פעם אחת, קבוע; בלי IT). B — אפליקציית Copilot הפרטית (בלי סוכנים: מדביקים טקסט פעם אחת בהגדרות, ב־Custom instructions). בסוכן של מסלול A, אם Code Interpreter לא זמין, השורה תסומן (estimated) והציון מקורב.

⚠ Two tracks: A — work/school account with Microsoft 365 Copilot (an agent you build once, permanent; no IT needed). B — personal Copilot app (no agents: paste a text once into Settings › Custom instructions). In the track A agent, if Code Interpreter is unavailable, the line is marked (estimated) and the score is approximate.

בונים את החבילה

Build the package

Illustration / המחשה

פתחו PowerShell בתיקייה שמכילה את prompt-score והריצו:

Open PowerShell in the folder that contains prompt-score and run:

powershell -ExecutionPolicy Bypass -File prompt-score\copilot\install.ps1

✔ תוצאה: מופיעה השורה Prompt Score v{{VERSION}} ({{DATE}}) ותיקיית dist נפתחת עם P1 ו־P2.

✔ Result: the line Prompt Score v{{VERSION}} ({{DATE}}) appears and the dist folder opens with P1 and P2.

⚠ הודעה שמתחילה ב־failed: מציינת מה נכשל, למה, ומה הצעד הבא — פעלו לפיה והריצו שוב. הדגל -ExecutionPolicy Bypass חל רק על הרצה זו.

⚠ A message containing failed: says what failed, why, and the next step — follow it and run again. -ExecutionPolicy Bypass applies to this one run only.

בונים את הסוכן ב־Agent Builder

Build the agent in Agent Builder

Illustration / המחשה — no IT needed; menu names can differ slightly between versions

ב־Microsoft 365 Copilot: Agents › New agent › Skip to configure. ב־START HERE.html, מסלול "Copilot בעבודה", העתיקו והדביקו Name, Description ו־Instructions (גם בקובץ P4). הדליקו את Create documents, charts, and code ולחצו Create.

In Microsoft 365 Copilot: Agents › New agent › Skip to configure. From START HERE.html, track "Copilot at work", copy and paste Name, Description and Instructions (also in file P4). Turn on Create documents, charts, and code, then click Create.

⚠ אין New agent? הארגון חסם יצירת סוכנים. חלופה: להעלות את P1 ב־Teams › Apps › Manage your apps › Upload an app › Upload a custom app, או לבקש מה־IT להעלות אותו (Microsoft 365 admin center › Integrated apps).

⚠ No New agent? Your organization blocked agent creation. Alternative: upload P1 in Teams › Apps › Manage your apps › Upload an app › Upload a custom app, or ask IT to upload it (Microsoft 365 admin center › Integrated apps).

3

פותחים את הסוכן ב־Copilot

Open the agent in Copilot

Illustration / המחשה

באפליקציית Microsoft 365 Copilot (או ב־Copilot Chat): בחלונית Agents בחרו Prompt Score. ייתכן שיחלפו כמה דקות עד שיופיע.

In the Microsoft 365 Copilot app (or Copilot Chat): in the Agents pane, pick Prompt Score. It may take a few minutes to appear.

בדיקה סופית

Final check

Illustration / המחשה — expected text comes from the scorer itself

שלחו fix it. התשובה צריכה להתחיל ב־Prompt score: 10/100 (weak). שלחו about — צפוי v{{VERSION}} מתאריך {{DATE}}.

Send fix it. The reply should start with Prompt score: 10/100 (weak). Send about — expect v{{VERSION}}, released {{DATE}}.

⚠ מופיע (estimated)? Code Interpreter לא זמין ברישיון/בסביבה שלכם; הציון מקורב. גרסה ישנה מופיעה? העלו שוב את P1 החדש — כל בנייה מעלה גרסה רק אם עודכן plugin.json.

⚠ Seeing (estimated)? Code Interpreter is not available in your license/tenant; the score is approximate. Old version shown? Upload the new P1 again — a rebuild only changes the version when plugin.json was bumped.

מעתיקים את הטקסט הקבוע

Copy the permanent text

Illustration / המחשה

ב־START HERE.html בחרו Copilot רגיל ולחצו העתקה. או פתחו את P3 והעתיקו את כל הטקסט. עם הסקריפט: הדגל -Consumer מעתיק את P3 ופותח את Copilot.

In START HERE.html pick Regular Copilot and click Copy. Or open P3 and copy all of it. With the script, -Consumer copies P3 and opens Copilot.

6

מדביקים ב־Custom instructions ושומרים

Paste into Custom instructions and save

Illustration / המחשה — menu names can differ slightly between Copilot versions

ב־Copilot: תמונת הפרופיל ‹ Settings ‹ Personalization ‹ Custom instructions. הדביקו (Ctrl+V), לחצו Save וודאו שההתאמה האישית מופעלת. בדקו בצ'אט חדש עם fix it כמו בשלב 4.

In Copilot: profile picture › Settings › Personalization › Custom instructions. Paste (Ctrl+V), click Save and make sure Personalization is On. Check in a new chat with fix it, as in step 4.

✔ קבוע: כל צ'אט חדש מקבל ציון בלי להדביק שוב. כאן Copilot מחשב לפי כללים מקוצרים, כך שהציון עשוי להיות שונה בכמה נקודות מהסוכן של מסלול A.

✔ Permanent: every new chat is scored without pasting again. Here Copilot applies shortened rules, so the score can differ by a few points from the track A agent.

⚠ אין Custom instructions או שהטקסט לא נכנס? גיבוי לצ'אט אחד: הדביקו את P2 כהודעה הראשונה בצ'אט חדש ושלחו; Copilot יענה ✅ Prompt Score is on. חוזרים על זה בכל צ'אט חדש.

⚠ No Custom instructions, or the text does not fit? One-chat backup: paste P2 as the first message of a new chat and send; Copilot replies ✅ Prompt Score is on. Repeat in every new chat.
