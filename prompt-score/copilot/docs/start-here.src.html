Prompt Score for Copilot

כל בקשה שתכתבו ל־Copilot תקבל ציון מ־1 עד 100 — וטיפ איך לנסח אותה טוב יותר.

Every request you write to Copilot gets a score from 1 to 100 — and a tip on how to word it better.

איזה Copilot יש לכם?

Which Copilot do you have?

1

לחצו "העתקה"

Click "Copy"

2

פתחו את Copilot

Open Copilot

פתיחת Copilot ↗Open Copilot ↗

או פתחו את אפליקציית Copilot במחשב והתחילו צ'אט חדש.

Or open the Copilot app on your computer and start a new chat.

3

הדביקו ושלחו

Paste and send

לחצו בתיבת הכתיבה, ואז Ctrl + V ואחר כך Enter.

Click in the message box, then press Ctrl + V and then Enter.

4

זהו! כתבו כרגיל

Done! Write as usual

מעכשיו, בצ'אט הזה, כל תשובה תתחיל בציון. נסו לכתוב: fix it

From now on, in this chat, every answer starts with a score. Try writing: fix it

Prompt score: 10/100 (weak) - biggest gap: Context…

⚠ זה עובד רק בצ'אט שבו הדבקתם. בצ'אט חדש — חזרו לדף הזה ובצעו שוב שלבים 1–3.

⚠ This works only in the chat where you pasted it. For a new chat, come back to this page and repeat steps 1–3.

1

פתחו את Teams והגיעו להעלאת אפליקציה

Open Teams and go to app upload

Apps›Manage your apps›Upload an app›Upload a custom app

בחרו את הקובץ {{AGENTZIP}} מהתיקייה הזו ולחצו Add.

Pick the file {{AGENTZIP}} from this folder and click Add.

⚠ אל תפתחו (unzip) את הקובץ הזה — מעלים אותו כמו שהוא.

⚠ Do not unzip this file — upload it as it is.

2

אין לכם "Upload a custom app"?

No "Upload a custom app"?

זה אומר שרק צוות ה־IT יכול להתקין. העתיקו את ההודעה ושלחו להם יחד עם הקובץ.

That means only your IT team can install it. Copy this message and send it to them with the file.

3

פתחו את הסוכן

Open the agent

באפליקציית Microsoft 365 Copilot (או ב־Copilot Chat) בחרו בצד Agents ואז Prompt Score. לפעמים לוקח כמה דקות עד שהוא מופיע.

In the Microsoft 365 Copilot app (or Copilot Chat), pick Agents on the side, then Prompt Score. It can take a few minutes to appear.

4

בדיקה

Check

כתבו fix it. התשובה צריכה להתחיל כך:

Write fix it. The answer should start like this:

Prompt score: 10/100 (weak) - biggest gap: Context…

✔ מעכשיו כל צ'אט עם Prompt Score מקבל ציון — אין צורך להדביק שוב.

✔ From now on every chat with Prompt Score is scored — no pasting needed.
