Prompt Score for Copilot

כל בקשה שתכתבו ל־Copilot תקבל ציון מ־1 עד 100 — וטיפ איך לנסח אותה טוב יותר.

Every request you write to Copilot gets a score from 1 to 100 — and a tip on how to word it better.

איזה Copilot יש לכם?

Which Copilot do you have?

1

לחצו "העתקה"

Click "Copy"

2

פתחו את ההגדרות של Copilot

Open Copilot settings

פתיחת Copilot ↗Open Copilot ↗

היכנסו עם החשבון שלכם, לחצו על תמונת הפרופיל או על השם שלכם, ואז:

Sign in, click your profile picture or name, then:

Settings›Personalization›Custom instructions

השמות יכולים להיות מעט שונים, למשל "הגדרות" ‹ "התאמה אישית" ‹ "הוראות מותאמות אישית". ודאו שההתאמה האישית מופעלת (On).

The names can differ slightly. Make sure Personalization is turned On.

3

הדביקו ושמרו

Paste and save

לחצו בתיבה של ההוראות, Ctrl + V, ואז Save / שמירה.

Click in the instructions box, press Ctrl + V, then Save.

4

בדיקה בצ'אט חדש

Check in a new chat

פתחו צ'אט חדש וכתבו: fix it. התשובה צריכה להתחיל בציון:

Open a new chat and write: fix it. The answer should start with a score:

Prompt score: 10/100 (weak) - biggest gap: Context…

✔ זהו — מעכשיו כל צ'אט חדש מקבל ציון, בלי להדביק שוב.

⚠ חשבון עבודה בלי "Custom instructions"? חזרו למעלה ובחרו Copilot בעבודה.

✔ Done — from now on every new chat is scored, no pasting again.

⚠ Work account without "Custom instructions"? Go back up and pick Copilot at work.

אין "Custom instructions" או שהטקסט לא נכנס? (גיבוי)No "Custom instructions", or the text does not fit? (backup)

אפשר להפעיל לצ'אט אחד בכל פעם: העתיקו, הדביקו כהודעה הראשונה בצ'אט חדש ושלחו. Copilot יענה ✅ Prompt Score is on. בכל צ'אט חדש חוזרים על זה.

You can turn it on for one chat at a time: copy, paste it as the first message of a new chat and send. Copilot replies ✅ Prompt Score is on. Repeat in every new chat.

✔ בלי צוות IT: בונים את הסוכן לבד, פעם אחת, ב־Copilot. אחר כך כל צ'אט עם הסוכן Prompt Score מקבל ציון.

✔ No IT needed: build the agent yourself, once, in Copilot. Then every chat with the Prompt Score agent is scored.

1

פותחים "סוכן חדש"

Open "New agent"

פתיחת Microsoft 365 Copilot ↗Open Microsoft 365 Copilot ↗

היכנסו עם חשבון העבודה (או פתחו את אפליקציית Microsoft 365 Copilot), ובצד:

Sign in with the work account (or open the Microsoft 365 Copilot app), and on the side:

Agents›New agent›Skip to configure

⚠ אם Copilot מתחיל לשאול "מה הסוכן צריך לעשות?" — חפשו את הכפתור Skip to configure או את הלשונית Configure.

⚠ If Copilot starts asking "what should the agent do?", look for the Skip to configure button or the Configure tab.

2

ממלאים 3 שדות — העתקה והדבקה

Fill 3 fields — copy and paste

לכל שדה: לוחצים "העתקה", לוחצים בשדה ב־Copilot, Ctrl + V.

For each field: click "Copy", click in the field in Copilot, Ctrl + V.

Name
Description
Instructions
3

מפעילים את המתג ויוצרים

Turn on the switch and create

תחת Capabilities הדליקו את Create documents, charts, and code (זה נותן ציון מדויק). אחר כך לחצו Create.

Under Capabilities turn on Create documents, charts, and code (this makes the score exact). Then click Create.

4

בדיקה

Check

בצד, תחת Agents, בחרו Prompt Score וכתבו fix it. התשובה צריכה להתחיל כך:

On the side, under Agents, pick Prompt Score and write fix it. The answer should start like this:

Prompt score: 10/100 (weak) - biggest gap: Context…

✔ קבוע: בכל פעם שבוחרים בסוכן Prompt Score, כל הודעה מקבלת ציון. צ'אט רגיל עם Copilot (בלי לבחור בסוכן) לא מקבל ציון.

✔ Permanent: whenever you pick the Prompt Score agent, every message is scored. A regular Copilot chat (without picking the agent) is not scored.

⚠ מופיע (estimated)? המתג משלב 3 כבוי או לא זמין בארגון — הציון מקורב, אבל עובד.

⚠ Seeing (estimated)? The switch from step 3 is off or not available in your organization — the score is approximate, but it works.

מה בדיוק מועתק? (לסקרנים)What exactly is copied? (for the curious)

התיבות: הטקסט הקבוע ל־Copilot הפרטי, הטקסט לצ'אט אחד, וההוראות לסוכן בעבודה. אם כפתור לא מעתיק: לחצו בתיבה, Ctrl+A ואז Ctrl+C.

Boxes: the permanent text for personal Copilot, the one-chat text, and the instructions for the work agent. If a button does not copy: click in the box, then Ctrl+A and Ctrl+C.
